# Reusable illustration skill

`ian-xiaohei-illustrations/` is the installable Ian Xiaohei Illustrations skill, from https://github.com/tojileon/ian-xiaohei-illustrations-en. Its original author is Ian; see the bundled LICENSE, NOTICE.md and SOURCE.md. The source commit is pinned in SOURCE.md. The skill bundle is unchanged, with upstream attribution files added.

It is also installed globally in `/Users/theharithsa/.codex/skills/ian-xiaohei-illustrations`, so Codex can discover it on the next turn in other projects.

Example request:

> Use $ian-xiaohei-illustrations to explain this project with three clean hand-drawn concept illustrations and a readable guide.

The skill uses the built-in image generation tool. It produces illustrations rather than editable architecture diagrams. Save project images into the project, not the installed skill folder. Keep license and attribution when sharing this bundle. Review upstream changes before replacing the pinned version.

The ChaiCart guide is `project-explained.html`; its illustrations, prompt set and QA manifest are in `assets/chaicart-project-illustrations/`.
